# University Management System

## 1. Project Overview
The **University Management System** is a web-based project designed to organize and display university-related information in a simple and structured manner.

The system provides separate sections for student and faculty information, making university data easy to access and understand.

## 2. Technologies Used
- HTML5 – To create the structure of web pages.
- CSS3 – To design and style the website.
- Visual Studio Code – For writing and editing code.
- GitHub – For project collaboration and version control.

## 3. Project Features
- Student Information Section
- Faculty Information Section
- Organized information using tables and cards
- Responsive web page layout
- Simple and user-friendly interface
- Consistent styling across web pages

## 6. How to Run the Project
1. Download or clone the GitHub repository.
2. Extract the project folder if downloaded as ZIP.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in a browser.
5. Navigate through the available sections.
