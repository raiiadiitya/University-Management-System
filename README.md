# University Management System

## 1. Project Overview
The **University Management System** is a web-based project designed to organize and display university-related information in a simple and structured manner.

The system provides separate sections for student information, faculty details, departments and courses, timetable, and university notices. It makes university information easy to access and understand through a simple and user-friendly interface.

## 2. Technologies Used
- **HTML5** – To create the structure of web pages.
- **CSS3** – To design and style the website.
- **JavaScript** – To add interactive features such as live search, active navigation, clickable dashboard cards, and live date and time.
- **Visual Studio Code** – For writing and editing code.
- **GitHub** – For project collaboration and version control.

## 3. Project Features
- Student Information Section
- Faculty Information Section
- Departments and Courses Section
- Timetable Section
- University Notices and Examination Schedule
- Organized information using cards and tables
- Responsive web page layout
- Simple and user-friendly interface
- Consistent styling across web pages
- Live search functionality on supported pages
- Highlighting of the active navigation link
- Live date and time display
- Clickable dashboard cards for easy navigation

## 6. How to Run the Project
1. Download or clone the GitHub repository.
2. Extract the project folder if downloaded as ZIP.
3. Open the folder in Visual Studio Code.
4. Make sure all HTML, CSS, and JavaScript files are in the same folder.
5. Open `index.html` in a browser or use the Live Server extension.
6. Navigate through the available sections using the navigation bar or dashboard cards.
